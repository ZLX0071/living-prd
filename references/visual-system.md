# 默认视觉系统

仅当用户没有提供视觉规范、没有已确认的 Demo 设计提取，或明确交由 Agent 决定时使用。采用本默认方案后，把实际选用的 tokens 和规则写入工作区 `reference/DESIGN.md`。

## 方向

白纸上的字段终端：近白画布、近黑文字、发丝边框，依靠对比与排版层级，不用装饰色、大面积背景切换或浮夸立体感。界面紧凑、精确，而不拥挤。

## Token

```css
:root {
  --paper: #fafafa;
  --surface: #ffffff;
  --hairline: #ebebeb;
  --muted: #666666;
  --secondary: #4d4d4d;
  --ink: #171717;
  --graphic-black: #000000;
  --success: #297a3a;
  --font-sans: "Geist Sans", Inter, ui-sans-serif, system-ui, sans-serif;
  --font-mono: "Geist Mono", "JetBrains Mono", ui-monospace, monospace;
  --radius-small: 2px;
  --radius: 6px;
  --page-max: 1280px;
}
```

## 排版与密度

- 正文 14–16px，字重 400，行高 1.43–1.5；主要文字 `#171717`，辅助文字 `#4d4d4d` / `#666666`。
- 大标题字重 400–450，紧字距；不使用 700+ 的粗重大标题。
- 标签、元数据、代码用 11–13px 等宽字体；大写标签可使用轻微加宽字距。
- 基于 4px 网格；元素常用间隔 8/12/16/24/32px，卡片内边距 16px。

## 组件

- **主按钮**：`#171717` 背景、白字、6px 圆角，字号 14px。
- **次按钮**：透明背景、`#4d4d4d` 文字、1px `#ebebeb` 边框、6px 圆角。
- **卡片**：白底、1px 发丝边框、6px 圆角；不使用投影。
- **反相卡片**：`#171717` 底、白字，仅作稀疏的视觉标点。
- **顶部导航**：64px 高、`#fafafa` 背景，可轻微背景模糊，无投影。
- **终端/数据面板**：白底发丝边框，12–13px 等宽字体，仅用 `#297a3a` 表示成功或短强调。

## 硬约束

- 禁止 Tailwind 默认蓝、紫及相近颜色。
- 禁止大面积渐变背景；默认不使用渐变。
- 矩形卡片和按钮圆角不超过 6px；仅紧凑标签或导航 pill 可用全圆角。
- 禁止重投影；层级优先用留白、线条和明度差。
- 原型中的图像必须服务于任务、信息或真实感，不添加无功能的装饰图。
