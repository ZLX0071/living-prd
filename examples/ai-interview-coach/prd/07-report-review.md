# 报告与错题本

## 目标与范围

- 目标：把一场练习变成"知道差在哪 + 明天怎么改 + 弱点不重复"的改进闭环。
- 范围：包含逐题评分卡、改进建议、整场总评与趋势、错题本、文本分享；不包含社区分享页、排行榜。
- 角色/前置：存在"已完练"场次；依赖 mock-interview 的作答记录。
- 原型页：`report-detail.html`（报告主页）、`mistake-book.html`（错题本）。

## 原子功能

### F-rep-01 逐题评分卡
- 角色/前置：场次已完练且报告生成成功。
- 触发：进入报告页。
- 主规则：每题按四维评分——结构 30 / 匹配度 30 / 深度 25 / 表达 15，总分四维加权；每个维度给 1 句评价，且至少引用 1 处用户原话；页面明确标注"AI 建议仅供参考"（对应 Q1 信任方案）。
- 数据输入/输出：输入作答记录；输出逐题评分与评价。
- 可见结果：报告头部总分环 + 四维分条；下方逐题卡。
- 异常/空/加载/权限状态：生成中→阶段文案；失败→重试；单题作答<20 字仍给分但标注"回答过短，分数参考性低"。
- 验收方式：每题评价均含原话引用（服务端校验）；评分抽样人评偏差 <10 分（D-02）。

### F-rep-02 改进建议
- 角色/前置：同 F-rep-01。
- 触发：逐题卡内展示。
- 主规则：每题给"参考要点（3-5 条）+ 你的答案差距 + 1 个可执行改进动作"；改进动作必须是下一步可练习的行为（如"补一个动作→机制→数据的归因句式"），不是空泛评价。
- 可见结果：改进动作用独立样式块呈现。
- 验收方式：每条动作包含动词开头且指向下次练习。

### F-rep-03 整场总评与趋势
- 角色/前置：同 F-rep-01。
- 主规则：总评 ≤3 句（最强项/最弱项/本场最值得练的一件事）；历史完练 ≥2 场时显示总分趋势与四维对比。
- 可见结果：趋势为细线图（demo 期静态示意）。

### F-rep-04 错题本
- 角色/前置：存在历史练习。
- 触发：完练后自动写入；用户随时进入。
- 主规则：入本规则——单题总分 <60 或该题使用了全部提示（2 次用尽）；状态"未掌握/已掌握"手动标记；"一键重练"携带原题与上次答案摘要进入单题精练；列表按来源岗位分组、按分数升序。
- 可见结果：错题卡显示题目/来源/得分/状态/操作。
- 异常/空状态：无错题显示空态（"暂时没有需要重练的题——保持节奏"）。
- 验收方式：<60 分题目 100% 出现在错题本；重练场次能追溯到原题。

### F-rep-05 报告分享
- 角色/前置：报告已生成。
- 主规则：复制为纯文本摘要（岗位、总分、四维分、3 条最关键改进动作）；不包含逐题原文，避免长文刷屏。

## 业务规则汇总

| 规则 ID | 规则 |
| --- | --- |
| CR-rep-01 | 四维 30/30/25/15 加权；评价必须引用用户原话 ≥1 处 |
| CR-rep-02 | 单题 <60 或提示用尽自动入错题本 |
| CR-rep-03 | 改进动作每题 1 条、动词开头、指向下次练习 |
| CR-rep-04 | 报告全局标注"AI 建议仅供参考" |

## 数据

- 报告：场次 id、逐题评分、总评、生成时间；错题：题 id、来源准备、得分、状态、入本时间。
- 与其他模块：错题重练回流 mock-interview（单题精练）；练习统计回写 prep-planner 岗位卡。

## 非功能约束

- 报告页打开 p95 < 1 秒（生成在完练时已完成）。
- 评分条必须有数值文本，不依赖纯颜色（可访问性）。
