# 岗位准备与题单

## 目标与范围

- 目标：让用户在 2 分钟内把一个岗位变成一份针对性练习计划（题单）。
- 范围：包含新建准备、题单生成、题单管理、准备列表；不包含简历文件解析、岗位订阅推送（见 S4 暂缓项）。
- 角色/前置：单机单用户（demo 期无账号体系）；无前置模块依赖。
- 原型页：`prep-home.html`（岗位准备主页面）。

## 原子功能

### F-prep-01 创建岗位准备
- 角色/前置：任意用户；无前置。
- 触发：点击"新建岗位准备"卡片中的"生成题单"。
- 主规则：公司名（1-30 字）与岗位名（1-30 字）必填；JD 文本 50-6000 字，可为空——为空时按岗位方向使用通用题库模板并在卡片上标注"通用题单"。
- 数据输入/输出：输入公司、岗位、JD 文本；输出准备对象（id/公司/岗位/JD/创建时间/进度/题单）。
- 可见结果：列表顶部出现新岗位卡，进入题单生成 loading。
- 异常/空/加载/权限状态：JD 超长输入框即时提示剩余字数并禁止提交；网络失败保留表单可重试；同名准备（公司+岗位相同）提示"已存在，是否打开"。
- 验收方式：提交后 1 秒内列表出现新卡片且状态为"生成中"。

### F-prep-02 题单生成
- 角色/前置：存在一个准备对象。
- 触发：F-prep-01 提交成功后自动执行；也可在卡片菜单中"重新生成"。
- 主规则：AI 基于 JD 关键要素 + 通用校拟能力模型生成 8-12 题；构成：行为面 4-6 题、专业面 2-4 题、项目追问 2-3 题（JD 为空时项目追问替换为通用能力题）；每题带考察点标签与难度（1-3）；生成期间显示阶段文案轮播（"正在分析 JD 能力要求…"→"正在匹配高频考点…"）。
- 数据输入/输出：输入 JD 与岗位方向；输出题单（题目/类型/考察点/难度）。
- 可见结果：卡片进度从"生成中"变为"题单 10 题 · 未练习"。
- 异常/空/加载/权限状态：生成失败保留准备对象并给"重试"；生成结果 <8 题视为失败自动重试一次。
- 验收方式：生成成功率 ≥98%（服务端）；题目均含考察点标签。

### F-prep-03 题单管理
- 角色/前置：题单已生成。
- 触发：在题单列表操作。
- 主规则：支持置顶（每准备最多 3 题）、移除、手动加题（每准备上限 20 题）。
- 可见结果：列表即时重排；被移除题目的练习记录保留在报告中。
- 异常：操作请求失败 toast 提示并回滚 UI。

### F-prep-04 准备列表
- 角色/前置：无。
- 触发：进入首页。
- 主规则：卡片显示公司/岗位/题数/已练题数/错题数/上次练习时间；按最近更新排序；点击卡片进入题单详情，从题单发起模拟。
- 可见结果：默认展开最近一个准备。
- 异常/空状态：无准备时显示空态引导（"粘贴你的第一份 JD"）。
- 验收方式：进度三项数字与练习记录一致。

## 业务规则汇总

| 规则 ID | 规则 |
| --- | --- |
| CR-prep-01 | JD 有效区间 50-6000 字；为空走通用题库并标注 |
| CR-prep-02 | 题单 8-12 题；<8 题视为失败自动重试 |
| CR-prep-03 | 手动加题上限 20；置顶上限 3 |

## 数据

- 准备对象：id、公司、岗位、JD、题单[]、练习统计（已练/错题）、创建/更新时间。
- 与其他模块：题单被 mock-interview 消费；练习统计由 report-review 回写。

## 非功能约束

- 题单生成 p95 < 15 秒；期间必须有阶段文案，不得白屏。
- 断网时表单内容本地保留。
