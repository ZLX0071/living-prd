# 模拟面试

## 目标与范围

- 目标：提供接近真实面试的作答体验——考官发问、针对答案追问、限时完成、练完即得报告。
- 范围：包含两种模式、对话作答、追问机制、提示、中断恢复、免费额度；不包含语音/视频、群面（暂缓项）。
- 角色/前置：存在至少一个题单；依赖 prep-planner 的题目数据。
- 原型页：`interview-session.html`（进行中主页面）、`interview-states.html`（边界状态展示页，kind: state-gallery）。

## 原子功能

### F-int-01 开始模拟
- 角色/前置：题单就绪；当日剩余完练额度 > 0。
- 触发：题单页点击"整场模拟"或单题"精练"。
- 主规则：整场模拟按题单顺序作答全部题目，默认 25 分钟软计时（超时仅顶部提醒，不强断）；单题精练只含 1 题及其追问，无整场计时；额度：每日 3 个"完练场次"（未完练/放弃不计），用尽后当日锁定并展示恢复时间（demo 期不接入支付）。
- 数据输入/输出：输入场次配置（模式/题目集）；输出场次（id/状态/消息流/提示余量）。
- 可见结果：进入面试页，第一题以考官气泡出现。
- 异常/空/加载/权限状态：额度用尽→开始按钮禁用并说明（状态页 quota-exhausted）；题单为空→按钮不可见。
- 验收方式：从点击到首题展示 p95 < 3 秒。

### F-int-02 对话作答与追问
- 角色/前置：场次进行中。
- 触发：考官发问后用户作答。
- 主规则：作答 20-2000 字（Enter 发送、Shift+Enter 换行）；AI 判定是否追问——答案含糊、缺量化结果、缺个人归因时追问 0-2 次；追问不得重复已问内容、不得超出题目考察范围；回答到位即进入下一题。
- 数据输入/输出：消息流（role/content/type）；输出用于评分的完整作答记录。
- 可见结果：对话流顺序展示考官/用户气泡，追问以虚线追问条呈现。
- 异常/空/加载/权限状态：空答案→行内提醒（连续 2 次建议跳过或请求提示）；发送失败自动重试 1 次并提示，答案不丢失；AI 超时（>15s）显示"考官思考中"。
- 验收方式：追问相关性人工抽检 ≥90%；答案零丢失。

### F-int-03 提示
- 角色/前置：本场提示余量 > 0（每场固定 2 次）。
- 触发：点击"提示"按钮。
- 主规则：展示当前题的考察点 + 答题框架（不直接给答案）；使用后本场余量减 1，该题在报告中标记"使用过提示"。
- 可见结果：提示卡片插入对话流；按钮文案更新"提示 · 剩 1 次"。
- 异常：余量为 0 时按钮禁用并说明。

### F-int-04 中断恢复
- 角色/前置：场次进行中。
- 触发：关闭页面/刷新/断网后返回。
- 主规则：场次与对话持久化，返回后恢复到当前题目与已有消息；主动"放弃本场"需确认（弹层说明：放弃不计为完练，对话保留至今日）。
- 可见结果：恢复后进度条与计时续接。
- 异常：本地数据损坏时降级为"从头开始本场"并提示。

### F-int-05 结束与转报告
- 角色/前置：整场全部题目作答完成。
- 触发：最后一题回答到位、AI 宣布面试结束。
- 主规则：自动进入报告生成 loading（预计 10-20 秒，阶段文案）；完成后跳转报告页；场次状态置为"已完练"，扣减当日额度。
- 异常：报告生成失败保留场次数据可重试。

## 业务规则汇总

| 规则 ID | 规则 |
| --- | --- |
| CR-int-01 | 追问 0-2 次/题，不重复、不超考察范围 |
| CR-int-02 | 提示 2 次/场，使用后题目在报告中留痕 |
| CR-int-03 | 完练 3 场/日免费；放弃与未完练不扣次数 |
| CR-int-04 | 作答 20-2000 字；Enter 发送 / Shift+Enter 换行 |
| CR-int-05 | 整场 25 分钟软计时，超时提醒不强断 |

## 数据

- 场次：id、模式、题目集、消息流、提示余量、状态（进行中/未完练/已完练/已放弃）、计时。
- 与其他模块：题单来自 prep-planner；完练结果触发 report-review 生成；额度计数独立存储。

## 非功能约束

- 消息发送到回显 p95 < 2 秒；断网自动重试 1 次。
- 对话流在 800px 视口内不出现横向滚动。
