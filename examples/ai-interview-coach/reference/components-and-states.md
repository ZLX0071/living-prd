# 组件与状态

> R2 设计参考基线：所有功能模块从这里取共享组件与状态定义；新组件先回写本文件与展示页，再在模块内使用。

## 全局导航与页框

- 顶栏：左侧 wordmark「▲ 面试陪练」，右侧全局导航（准备 / 面试 / 报告 / 错题本），当前项近黑反白。
- 内容区：最大宽 1180 居中；面试对话页收窄至 880 提升阅读节奏。
- 页面切换用原生链接 + `data-nav`（见数据契约"原型导航协议"），底座同步高亮与画布关系。

## 共享组件清单

| 组件 | 变体 | 用途 | 禁用条件 |
| --- | --- | --- | --- |
| 按钮 | primary / 次级 / 禁用 | 主操作近黑反白 | 生成中、额度用尽、空输入 |
| 文本输入 | 单行 / 多行（自动增高） | 公司/岗位/JD/作答 | — |
| 岗位卡 | 进行中 / 已完练 | 准备对象入口 | — |
| 对话气泡 | 考官 / 用户 / 追问条 | 面试对话流 | — |
| 标签 | 考察点 / 难度 / 状态 | 题目与错题标注 | — |
| 评分条 | 维度分（30/30/25/15 满分） | 报告 | — |
| 进度 | 场次进度条 + mono 计时 | 面试页顶 | — |
| 空态 | 无准备 / 无错题 | 引导下一步 | — |
| Toast | 成功 / 失败 | 轻反馈 | — |

## 跨模块状态

| 状态 | 定义 | 使用位置 |
| --- | --- | --- |
| loading | 生成/评分等待，骨架或阶段文案轮播 | 题单生成、报告生成 |
| empty | 无数据引导 | 准备列表、错题本 |
| error | 网络/服务失败 + 重试 | 生成、作答发送 |
| disabled | 不可用原因可见 | 额度用尽时的开始按钮 |
| quota-exhausted | 每日 3 完练场次用尽 | 面试入口 |
| exit-confirm | 放弃场次确认弹层 | 面试页 |
| success | 完成反馈（✓） | 生成成功、标记已掌握 |

状态展示页：`prototypes/pages/states.html` 并列展示以上状态；组件展示页：`prototypes/pages/components.html`。
